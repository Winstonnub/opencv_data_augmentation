# OpenCV Image augmentation

- This repository is mainly used by myself to learn how to use the opencv library, but if you find it useful you may use it as you wish.

###Quick Start 
``` 
pip install opencv-python numpy
```

### Folder Structure
.
├─ pics/            # your input images (.jpg/.png/…)

├─ output/          # augmented images will be saved here
